# Repository instructions

When the user asks to realign this skills repo (for example, **“re-align skills,” “realign my skills,”** or **“align skills again”**), run [`docs/skill-alignment.md`](docs/skill-alignment.md). Start with a read-only comparison and present its report before syncing anything. Include external-candidate review in the same session, using the question tool to decide what to add. Preserve local adaptations and extras unless the user explicitly approves changing them.
